# WEARTICLE - 微文章阅读网站

一个聚焦于微文章分享类型网站，以简洁美观的布局 + 轻量交互，呈现独特的视觉效果。


## 项目技术栈
该项目基于 **Vue 3 + Vite** 构建，是面向前端作业/小型科普站点的轻量方案：
- 前端框架：Vue 3（采用 Composition API 开发）
- 构建工具：Vite（实现快速热更新、高效打包）
- 路由管理：Vue Router（实现页面/内容区块的导航跳转）
- 样式方案：原生 CSS（含响应式设计、自定义组件样式）
- 运行依赖：Node.js 16.0.0 及以上版本


## 环境准备
确保本地已安装：
- Node.js：v16.0.0 或更高版本（[下载地址](https://nodejs.org/)）
- 包管理工具：npm（Node 自带）或 yarn


## 项目使用步骤
克隆/获取项目

将项目文件下载到本地后，进入项目终端：
```bash
# 进入项目根目录
cd weArticle

# 下载模块
npm install

# 启动项目
npm run dev

#在本地浏览器打开项目网址即可正常使用
```
